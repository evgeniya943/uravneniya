# uravneniya
Перед вами приложение-викторина с четырьмя случайными математическими задачами (сложение, вычитание, умножение, деление) и таймером обратного отсчета. 

В правом верхнем углу у нас находится таймер. 

В центральной части четыре строки примеров.

Нижняя часть кнопка запуска.

Ваша задача, нажать на кнопку старта и пока не закончится время решить математические задачи разной сложности.
